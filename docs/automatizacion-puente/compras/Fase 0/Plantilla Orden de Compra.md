## Notas de uso
- El **TOTAL bruto (con IVA)** es el valor que determina el tramo de aprobación.
- La OC no se emite si el proveedor no está **Apto** (SII vigente + datos bancarios completos).
- Al emitirse en Manager+, anotar el **N° OC** y volcarlo al registro `Ordenes_Compra` en Zoho y al nombre de la carpeta del expediente.

## Entrega
Esta plantilla conviene materializarla en **Word o Excel** para uso real. Pídeme la conversión cuando quieras el archivo `.docx`/`.xlsx`.
